软件回环通过、空口 Find=0 的排查
==============================

当前设备：A3 发射地址 `192.168.1.102`，E200 接收地址 `192.168.1.11`，E200 天线接 RX1。先检查射频通道和实际 IQ；访问码检测仍为零时，ROS 没有消息是该接收链路的正常后果。

**1. 接收程序实际启用 RX1**

原仓库的红、蓝接收程序均启用 RX2。已将本地 `.py` 和对应 `.grc` 默认改成 RX1、URI 改成 `ip:192.168.1.11`。你的 Linux 接收脚本可能已做过 ZeroMQ、录波路径等修改，优先只同步以下配置，而不是用旧整文件覆盖。

在 Linux 的 `GFSK_RX_RED.py` 中确认接收源为：

```python
self.iio_fmcomms2_source_0 = iio.fmcomms2_source_fc32(
    'ip:192.168.1.11', [True, True, False, False], 65536)
```

四个布尔值分别启用 RX1 的 I/Q、RX2 的 I/Q；这组参数只启用 RX1。增益模式要配置索引 0：

```python
self.iio_fmcomms2_source_0.set_gain_mode(0, 'slow_attack')
```

原先 `if False` 配置 RX1、`if True` 配置 RX2 的两段，需要同步改成 RX1=True、RX2=False，或以以上 RX1 增益配置替换这两段。GRC 的 FMComms Source 对应设置为 RX1=True、RX2=False。修改后重启接收进程；原进程不会自动载入修改。

**2. 确认收发在同一时间运行，频率对应**

先启动接收。再在你之前运行发射命令的目录运行以下命令，保持发射直到 Ctrl+C：

```bash
python3 tools/rm_sdr_tx.py \
  --mode tx --uri ip:192.168.1.102 \
  --side red --message position --tx-channel 1 \
  --attenuation 40 --duration 0
```

原来的 `--duration 10` 会在十秒后停止。如果收发进程未重叠，就无法接到测试帧。测试命令将内部衰减从原默认 60 dB 改成 40 dB，相同其他条件下输出提高 20 dB；数值越大，发射越弱。使用与频点匹配的天线，或按设备输入限值配置带衰减的同轴测试通路。

| 项目 | 当前红方坐标测试配置 |
| --- | --- |
| A3 TX1 中心频率 | 433.200 MHz |
| A3 采样率 / SPS | 2 MSa/s / 94 |
| E200 RX1 本振 | 432.600 MHz |
| 接收主支路数字偏移 | +600 kHz |
| 抽取后采样率 / SPS | 1 MSa/s / 47 |

因此 E200 本振不需要改成 433.200 MHz 后还保留 +600 kHz 偏移；本振加主支路偏移才是目标信道中心。

**3. 仍为零时，用探测工具看原始 IQ**

先停止 `GFSK_RX_RED.py`，释放 E200，再运行新工具。ROS 节点可保持运行；探测工具不向 ROS 发布数据。

```bash
# 在模拟发射工具包目录，tools/ 下有 sdr_rx_probe.py。
python3 tools/sdr_rx_probe.py \
  --uri ip:192.168.1.11 --rx-channel 1 \
  --frequency 432600000 --target-offset 600000 --duration 0
```

探测器使用固定 RX 增益 40 dB，每秒打印一条 JSON。先让 A3 停止发射观察几条，再启动第二步的发射命令，比较开关前后的结果。结束时按 Ctrl+C。

| 输出字段 | 含义 |
| --- | --- |
| `target_power_dbfs` | 主信息波中心 ±100 kHz 范围内的数字信号功率 |
| `target_peak_rf_hz` | 这个范围内的最强谱峰射频频率 |
| `strongest_offset_hz` | 整个采样带宽内的最强谱峰相对本振的偏移，已去除均值 DC |
| `peak_sample` | IQ 样本幅度最大值 |
| `clipped_percent` | I 或 Q 绝对值达到 0.98 的样本比例，用于发现削顶 |
| `observed_samples_per_second` | 主机实际处理的样本速率估计 |

这些功率数值是相对数字参考的 dBFS，不能当作天线口实际 dBm。默认测试频偏为 ±20 kHz，空闲字节为全零，所以常见主峰在 433.180 MHz 附近；数据期间也可能出现 433.220 MHz 一侧的能量。判断依据是 A3 开关后目标功率与谱峰是否明显变化，而不是要求某个固定 dBFS 数值。

若开关发射时目标频带完全不变，先查发射是否仍在运行、TX1/RX1 天线与程序通道是否对应、天线是否覆盖 433 MHz，以及实际中心频率。若频带明确有信号但仍无法识别访问码，再结合峰值偏移排查频差、采样参数和解调判决，先不要降低 CRC 要求。

**本地验证**

测量函数包含已知 580 kHz 偏移、幅度 0.1 的合成复数正弦测试，以及静默输入、削顶和非法频带测试。实际 IIO 采样和你的无线链路仍需在 Linux 上验证。
