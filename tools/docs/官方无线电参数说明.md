# 官方无线电参数与录波参数的区别

核对日期：2026-11-19。本页区分官方发射波形参数、接收工程配置和未知录波元数据。

## 2026 V2.2.0 官方定义

依据《RoboMaster 2026 机甲大师超级对抗赛比赛规则手册 V2.2.0（20260807）》表 5-23（印刷页 119–120）及附录 1（印刷页 152–153）。官方版本下载入口：[RMUC 2026 比赛规则文件](https://bbs.robomaster.com/wiki/20204847/809871)。

调制方式为 2-GFSK，映射为 0 → -1、1 → +1。高斯滤波参数的参考采样率为 1 MSa/s，SPS=47，BT=0.35。由此计算符号率及二进制比特率约为 21.2766 kbit/s，每 bit 时长 47 μs。

| 波源 | 红方中心 / MHz | 蓝方中心 / MHz | 带宽 / MHz | Sensitivity / rad/sample |
| --- | --- | --- | --- | --- |
| 信息波 | 433.200 | 433.920 | 0.54 | 1.5628 |
| 一级干扰波 | 432.200 | 434.920 | 0.94 | 2.8194 |
| 二级干扰波 | 432.500 | 434.620 | 0.86 | 2.5681 |
| 三级干扰波 | 432.800 | 434.320 | 0.25 | 0.6517 |

信息波标称功率为 -60 dBm，干扰波为 -10 dBm。此为官方广播源定义，不是联调工具或实验设备需要照设的发射功率。

空口包总长为 27 字节：

```text
Access Code 8字节 + Header 4字节 + Payload 15字节
```

- 信息波 Access Code：`2F6F4C74B914492E`。
- 干扰波 Access Code：`16E8D377151C712D`。
- Header 为两份相同的大端 16 bit 长度 `000F`，即 `000F000F`；官方要求两份不一致时丢弃。
- 红蓝双方使用相同的 Access Code。
- 应用数据流连续切为 15 字节片段，不足一个应用帧时需要后续重组，再执行应用层 CRC 校验。
- 无独立前导码、无固定包间隔、无白化、无 FEC；高斯滤波截断长度为 4 个符号周期。

这些物理层与空口结构已在本次官方规则核对中找到依据；以前工具文档中“尚未取得官方参数”的说法应按此更新。原模拟发射工具仍采用联调波形，并未因此自动变为完整的官方广播源模拟器。

## 为什么 WHU 是 SPS=52，RM_sdr 是 SPS=47

官方 2026 旧版 V1.4.2（20260430）表中使用 SPS=52、参考采样率 1 MSa/s、BT=0.35；信息波 Sensitivity 为 1.5756，其余等级分别为 2.8323、2.5809、0.6646。可核对[官方 V1.4.2 英文规则 PDF](https://bbs-web-static.robomaster.com/1f59fe9c9d154752a5e456e1f7139d4c1777519819115/RoboMaster%202026%20University%20Championship%20Rule%20Manual%20V1.4.2%EF%BC%8820260430%EF%BC%89.pdf)的电磁波参数表。

用户提供的 WHU 流图参数与这套旧值相符；当前 RM_sdr 的 SPS=47 与 V2.2.0 相符。本次按用户提供的 47 μs/bit 作为测试前提，自动文件测试默认采用该时序，只比较三种录波保存位置。旧版 52 μs 参数保留为显式可选项，不再默认测试。文件的实际采样率和保存位置仍须另行验证。

## 官方参考采样率不是录波文件采样率

官方的 1 MSa/s 用于描述调制波形。接收 SDR 可以用 2 或 3 MSa/s 采集同一个空中信号，然后频移、滤波、抽取至 1 MSa/s。

例如接收中心设为 432.700 MHz 时，433.200 MHz 信息波在原始 IQ 中处于 +500 kHz；频移到 0 Hz 后，得到单信道 IQ。432.700 MHz 是接收工程选择，+500 kHz 是两者频差，都不是官方要求必须采用的接收参数。

录波文件自身的采样率与目标相对偏移取决于 File Sink 的保存位置，不能因为官方表中写了 1 MSa/s，就给未知原始录波强行填写 1 MSa/s。CRC 解码通过也不能唯一恢复历史 RF 本振。
