# 固定参数与命令选项

## 官方造波参数

采用 [RMUC 2026 比赛规则 V2.2.0](https://bbs.robomaster.com/wiki/20204847/809871)表 5-23、附录 1，以及《RoboMaster 2026 机甲大师高校系列赛通信协议 V2.0.0（20260626）》第 1.6 节。2027 V1.0.0 的干扰参数尚待发布，具体版本见[官方规则入口](https://bbs.robomaster.com/wiki/20204847/1969149)。

| 参数 | 固定值 |
| --- | --- |
| 调制 | 2-GFSK，0→−1、1→+1 |
| 官方参考采样率 / SPS | 1 MSa/s / 47 |
| 实际 TX IQ 采样率 / SPS | 2 MSa/s / 94 |
| 每 bit 时间 | 47 μs |
| Gaussian BT / 截断长度 | 0.35 / 4 个符号 |
| 软件接收抽取 | 2 倍，得到 1 MSa/s、SPS=47 |
| TX1 基带最强载波幅度 | 0.2 |
| 造波数据周期 | 0.3 s，包序号在周期内递增 |
| 信息流 | 0x0A01～0x0A05 各 10 Hz，合计 1400 byte/s |
| 干扰流 | 0x0A06 为 10 Hz，其余随机填充，合计 1350 byte/s |

| 波形 | 红方 RF / MHz | 蓝方 RF / MHz | 标称带宽 / kHz | 灵敏度，1M参考 / rad/sample | 实际2M灵敏度 | 目标功率 / dBm |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `info` | 433.200 | 433.920 | 540 | 1.5628 | 0.7814 | −60 |
| `jam1` | 432.200 | 434.920 | 940 | 2.8194 | 1.4097 | −10 |
| `jam2` | 432.500 | 434.620 | 860 | 2.5681 | 1.28405 | −10 |
| `jam3` | 432.800 | 434.320 | 250 | 0.6517 | 0.32585 | −10 |

TX LO 固定为红方 **432.600 MHz**、蓝方 **434.520 MHz**；所选载波通过数字频移放到上表 RF。即使只发一路，也采用这个 LO。灵敏度随实际采样率缩放，以保持官方的真实频偏与比特时长。

功率字段为输出目标。未校准时不能把硬件衰减数值当作 dBm；校准和手动台架衰减的用法见 [README](README.md#功率校准)。组合波的数字幅度比为 `10^(-50/20)`，最终射频功率差仍需测量确认。

### 空口与应用帧

```text
信息访问码：2F6F4C74B914492E
干扰访问码：16E8D377151C712D

物理包：访问码 8 B + 长度头 000F000F 4 B + 连续数据片段 15 B = 27 B
应用帧：A5 + 小端长度 + 序号 + CRC8 + 小端命令码 + 业务数据 + CRC16
```

不添加独立前导码、白化或 FEC。数据每 100 ms 到达一次，完整 15 字节片段连续发射，等待新数据时关闭 RF；没有人为设定的固定逐包间隔。分片不在应用帧边界重新补齐。

| 命令 | 数据 | 数据长度 |
| --- | --- | ---: |
| 0x0A01 | 六台机器人坐标 | 24 B |
| 0x0A02 | 血量及保留位 | 12 B |
| 0x0A03 | 五项允许发弹量 | 10 B |
| 0x0A04 | 金币、宏观状态 | 8 B |
| 0x0A05 | 五台地面机器人增益、哨兵姿态、主要状态 | 41 B |
| 0x0A06 | 六位字母或数字密钥 | 6 B |

## 现场录波参数

格式均按小端 CF32 IQ 保存：每个复数点为 float32 I 和 float32 Q，共 8 字节。可用文件的预设为 **2 MSa/s 回放、每 bit 104 个文件采样点、接收抽取 2 倍后 SPS=52**。此解释对应 52 μs/bit，回放不改为官方造波的 47 μs。

解调这批录波时可参考 [RMUC 2026 V1.4.2（20260430）电磁波参数表](https://bbs-web-static.robomaster.com/1f59fe9c9d154752a5e456e1f7139d4c1777519819115/RoboMaster%202026%20University%20Championship%20Rule%20Manual%20V1.4.2%EF%BC%8820260430%EF%BC%89.pdf)，其参考采样率为 1 MSa/s，SPS 为 52。红蓝各档的频率间距大小相同，干扰波相对本方信息波的偏移在红方为 −1000、−700、−400 kHz，在蓝方为 +1000、+700、+400 kHz。这个关系适用于共用一个接收中心的频谱。单独保存的文件应分别确定各自的 IQ 偏移。

| `--recording` | 原文件 | 相对文件 0 Hz 的信道提取偏移 / Hz | 接收滤波完整宽度 / Hz | 接收 SPS | 已有 CRC 有效帧参考 |
| --- | --- | ---: | ---: | ---: | ---: |
| `red` | RX_RED | +718000 | 540000 | 52 | 429 |
| `blue` | RX_BLUE | 0 | 540000 | 52 | 327 |
| `blue-ganrao-1` | RX_BLUE_ganrao_1 | 0 | 940000 | 52 | 572 |
| `blue-ganrao-2` | RX_BLUE_ganrao_2 | 0 | 860000 | 52 | 643 |
| `blue-ganrao-3` | RX_BLUE_ganrao_3 | 0 | 250000 | 52 | 697 |

表中的滤波宽度用于从 IQ 提取目标信道。录制设备当时的模拟带宽和接收本振没有记录。录波软件环回的提取过渡带固定为 20000 Hz。上表 CRC 数值是文件参数的独立分析参考；不同滤波器和 GNU Radio 调度得到的帧数可能不同，接收成功以 CRC 有效数据为准。

### 自动回放的射频落点

**文件等效射频中心**是文件里的 0 Hz 在录制时所对应的射频频率。确认录到的信号原本在哪个射频频点，并按文件采样率换算出信号偏移后，即可用 `原信号射频中心 − 文件内信号偏移` 反推文件等效中心。

**录制设备 RX LO** 是接收机当时的调谐中心。直接保存 SDR 源输出时，文件等效中心可用来估计设备 RX LO。若保存前对 IQ 做了数字频移，两者会相差频移量。当前缺少当时的调谐和保存点记录，设备 RX LO 列填「未知」。

**TX LO** 是回放时设给 A3 的发射本振，它决定文件的 0 Hz 放到哪个射频频率。**RF 目标**是希望目标信号在空口出现的中心频率，RF 指射频。回放保留文件内的偏移，因此 `TX LO = RF 目标 − 文件内信号偏移`。

| 录波 | 录制设备 RX LO | 回放率 / Sa/s | 文件内信号偏移 / Hz | 回放 TX LO / Hz | 选定 RF 目标 / Hz |
| --- | --- | ---: | ---: | ---: | ---: |
| `red` | 未知 | 2000000 | +718000 | 432482000 | 433200000 |
| `blue` | 未知 | 2000000 | 0 | 433920000 | 433920000 |
| `blue-ganrao-1` | 未知 | 2000000 | 0 | 434920000 | 434920000 |
| `blue-ganrao-2` | 未知 | 2000000 | 0 | 434620000 | 434620000 |
| `blue-ganrao-3` | 未知 | 2000000 | 0 | 434320000 | 434320000 |

例如，若 `red` 录到的确实是 **433.200 MHz** 的信息波，按 **2 MSa/s** 得到的信号偏移约为 **+718 kHz**，则文件等效中心约为 **432.482 MHz**。回放也要让信号落到 433.200 MHz 时，TX LO 就取这个数值。其余行同理：当录到的信号频率等于表中的 RF 目标时，表中的 TX LO 也是该文件等效中心的估计值。

文件内偏移以 **2 MSa/s** 标定，这是能成功解码的回放速率解释。原录制采样率和实际射频频点没有随文件记录，RF 目标按测试所选信道填写。要确认录制设备的 RX LO，需要原来的 SDR Source 设置以及 File Sink 前的处理链路。

`RX_RED` 和 `RX_BLUE` 的信息波谱峰在相对平移约 720 kHz 后吻合。如果两份文件分别用红、蓝信息波的标称频点录制，`RX_RED` 里可解的是位于 433.92 MHz 附近的信息波。应在估算原录制中心前确认文件里的实际信号频点，避免直接按文件名推定。

## 命令参数

### `tx/official_tx.py`

| 参数 | 可用值 / 默认值 |
| --- | --- |
| `--side` | `red`、`blue`；默认 `red` |
| `--wave` | `info`、`jam1`、`jam2`、`jam3`；默认 `info`；允许 `info jam1` 等一个信息波加一档干扰 |
| `--data` | 业务数据 JSON；默认 `tools/config/messages.json` |
| `--uri` | 发射 SDR IIO 地址；默认 `ip:192.168.1.102` |
| `--duration` | 发射秒数，默认 10；0 表示持续到 Ctrl+C |
| `--attenuation` | 0～89.75 dB，手动台架衰减；省略时使用 `config/power.json` 校准 |
| `--describe` | 只打印参数，不连接硬件 |

### `tx/replay_tx.py`

| 参数 | 可用值 / 默认值 |
| --- | --- |
| `--recording` | 上表五个可用索引之一 |
| `--recording-dir` | 原始录波目录；默认 Linux 工程同级 `Info`、Windows 工程同级“信息波录制” |
| `--uri` | 发射 SDR IIO 地址；默认 `ip:192.168.1.102` |
| `--attenuation` | 0～89.75 dB；默认 60 |
| `--duration` | 最长播放秒数；默认 0，单次到 EOF、循环到 Ctrl+C |
| `--repeat` | 循环播放；默认单次 |
| `--list` | 列出录波和可用状态 |
| `--describe` | 只打印预设，不连接硬件 |

### `test/loopback.py`

| 参数 | 可用值 / 默认值 |
| --- | --- |
| `--side` | `red`、`blue`；生成波形时使用，默认 `red` |
| `--wave` | 与官方造波入口相同；默认 `info` |
| `--data` | 生成波形的业务数据 JSON；默认 `tools/config/messages.json` |
| `--recording` | 指定后改用现场 IQ，自动选择波形、阵营标签、偏移和时序 |
| `--recording-dir` | 录波目录覆盖 |
| `--describe` | 只打印配置 |

此入口不打开 SDR，不绑定 ZeroMQ。返回码 0 表示所选通道全部通过 CRC/内容检查，1 表示至少一路未通过，2 表示配置或环境错误。组合干扰可能导致信息波无法解码。

### `rx/project_rx.py`

| 参数 | 可用值 / 默认值 |
| --- | --- |
| `--side` | `red`、`blue`；默认 `red` |
| `--sps` | `47` 用于官方造波、`52` 用于本批实录；省略时沿用工程配置 |
| `--uri` | 接收 SDR IIO 地址；省略时沿用工程配置 |
| `--jam3` | 将原第二档干扰支路换为第三档；默认不启用 |
| `--describe` | 只打印配置 |

默认接收参数读取工程流图：采样率 2 MSa/s、抽取后 1 MSa/s，信息/干扰由原 OOT 模块解码，输出保留本机 ZeroMQ 5555/6666/6667。
